# SSM 2027 메인 페이지 (Wix 임베드용)

superspeedrun.com 메인 페이지를 SSM 2027 포스터 컨셉에 맞춰 새로 만든 것이다.
Wix 요금제가 남아 있어서 사이트는 Wix에 그대로 두고, 메인 페이지 본문만 HTML로 만들어 Wix의 **HTML 임베드** 요소에 넣는 방식으로 했다.

## 파일

| 파일 | 설명 |
|---|---|
| `ssm-main-wix.html` | Wix에 붙여넣는 최종본. 이미지가 전부 파일 안에 들어 있어서 이 파일 하나면 된다. |
| `src.html` | 수정용 원본. 이미지를 `assets/` 폴더에서 불러온다. |
| `build.py` | `src.html`의 이미지를 파일 안에 넣어 `ssm-main-wix.html`을 만든다. |
| `assets/` | 로고, 이미지 원본 |

## 왜 이렇게 만들었나

### Wix 편집기 대신 HTML 임베드
Wix 편집기는 편집이 불편하고 원하는 디자인을 내기 어려웠다. HTML 임베드를 쓰면 Wix 사이트, 도메인, 기부 페이지, 블로그는 그대로 쓰면서 메인 본문만 자유롭게 만들 수 있다.

### 디자인은 포스터 기준
`ssm2027_공유용_out (2).ai` 포스터를 그대로 따랐다.
- 상단 `Estimate 75:00 / Season Winter / Goal 10M WON` 줄
- SSM 로고, 배경 방패 엠블럼, 한글 타이틀, 날짜 `2027. 01. 21 - 24`
- 장소, 방송, 협력, 후원, 제작 영역은 포스터 하단처럼 빨간 점선 발판과 파란 사다리 구조로 배치했다. 모바일에서는 사다리를 빼고 발판만 평평하게 남긴다.
- 섹션 구분선도 회색 선 대신 포스터의 빨간 점선 발판을 쓴다. 발판은 좌우로 엇갈리게 살짝 기울였고, 일부 섹션은 제목과 본문 사이에 파란 사다리를 세워 발판끼리 잇는다(동키콩 구조).
- 섹션 제목 앞에는 포스터의 ✚ 표시를 픽셀로 넣었다. 버튼과 지난 행사 타일은 모서리를 계단식 픽셀 모양으로 깎았다.
- 색은 포스터 로고 색(노랑 `#ffef00`, 빨강 `#eb3728`, 파랑 `#0087c9`)을 쓴다.
- 배경은 검정(`#000`). 포스터 이미지의 회색 배경은 잘못 나온 색이라 쓰지 않았다.

### 폰트는 갈무리로 통일
포스터의 픽셀 느낌에 맞춰 전부 [갈무리](https://galmuri.quiple.dev/)를 쓴다. 제목과 라벨은 Galmuri11, 긴 본문은 Galmuri14다. 폰트는 jsdelivr CDN에서 불러온다.

### 텍스트는 기존 사이트 문구 그대로
문구를 새로 쓰면 AI가 쓴 글처럼 보여서, 기존 superspeedrun.com 홈 문구와 포스터 문구를 그대로 가져왔다. 새로 쓴 문장은 없다.
- 기존 사이트에서 운영팀 소개에 붙어 있던 "자주 묻는 질문" 제목은 쓰지 않았다.
- 문의 부분은 "담당자"와 "문의하기" 제목이 겹쳐서 "문의하기"만 남겼다.

### 장식 최소화
처음 시안에 있던 화면 줄무늬 효과, 깜빡이는 글자, 아이콘 카드, 큰 카운트다운 타이머, 게임풍 문구("PRESS START" 등)는 AI 템플릿처럼 보여서 모두 뺐다. 장식은 포스터에 있는 요소(엠블럼, 발판, 사다리, 3색 어긋남 글자)만 쓴다.

### 헤더, 바닥글, 운영팀 제외
- 상단 메뉴와 바닥글은 Wix 사이트에 이미 있으므로 뺐다.
- 운영팀 소개는 메인에서 뺐다.

## 링크

`src.html` 맨 아래 `CONFIG`에 모여 있다.

- 기부: https://www.superspeedrun.com/donation
- 방송 보기, 치지직 로고: https://chzzk.naver.com/e0e794139a00ce8179cb11e714a0e823
- 지난 행사 6개: 기존 Wix 페이지 주소 그대로

Wix 안의 페이지(기부, 지난 행사)는 현재 창에서 열리고(`target="_top"`), 외부 사이트(치지직, 유튜브, 디스코드, 바다게임즈)는 새 창에서 열린다.

## Wix에 넣는 방법

1. `ssm-main-wix.html`을 텍스트 편집기로 열어 전체 복사한다.
2. Wix 편집기에서 **추가 → 임베드 코드 → HTML 임베드**를 선택하고, **코드** 탭에 붙여넣은 뒤 **업데이트**를 누른다.
3. 요소 너비를 페이지 전체로 늘린다. 높이는 **데스크톱 4,190px**, **모바일 4,690px**(Wix 모바일 편집 화면, 너비 320px 기준)로 맞춘다. 모바일 높이는 Wix 모바일 편집 화면에서 따로 맞춰야 한다.

## 수정하는 방법

1. `src.html`을 고친다. 링크는 `CONFIG`, 문구는 HTML 본문에 있다.
2. 이 폴더에서 `python3 build.py`를 실행하면 `ssm-main-wix.html`이 다시 만들어진다.
3. 새 `ssm-main-wix.html`을 Wix 임베드에 다시 붙여넣는다.

## 알아둘 점

- HTML 임베드는 내부적으로 iframe이라, 그 안의 글자는 Wix 기본 텍스트보다 검색엔진에 덜 잡힌다.
- 이미지를 전부 파일 안에 넣어서 코드가 약 30만 자다. Wix가 길이 때문에 받아주지 않으면, `assets/` 이미지를 Wix 미디어에 올리고 `src.html`의 이미지 경로를 그 주소로 바꾸면 된다.
- Wix 임베드는 높이를 자동으로 맞추지 못한다. 그래서 브라우저 폭에 따라 글 줄바꿈이 달라져 내용이 길어지면 임베드 안에 스크롤이 생겼다. 이를 막으려고 데스크톱에서는 본문 너비를 920px로 고정하고 글자와 로고 크기도 고정값으로 바꿨다. 이제 데스크톱(980px 이상)에서는 브라우저 폭과 상관없이 높이가 항상 같다. 960px 이하에서만 모바일 레이아웃으로 바뀐다.
- 내용을 고쳐 길이가 달라지면 Wix에서 임베드 높이를 다시 맞춰야 한다.
